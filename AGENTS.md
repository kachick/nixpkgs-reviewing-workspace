# Rules for AI Agents

## Reference Projects

- **General Structure**: Follow patterns in [kachick/workflows](https://github.com/kachick/workflows).

## Reporting Policy

- **Keep Original Output**: Do not modify the original `nixpkgs-review` output format. The only exception is combining the shared header across multiple platform reports to avoid duplicate text. Place custom metadata (such as the workflow run link) in the markdown footer after a horizontal rule (`---`).
